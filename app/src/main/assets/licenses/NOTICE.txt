The base contributes 3,706 profiles and 140,949 command associations.
TV ordering metadata derives from these same source brand trees and Malaysian
regional priorities; its generator/provenance is under tools/mi_matching.

Five Astro profiles and 216 commands derive from anonymous development-time
queries to Xiaomi's public regional STB service, brand 3833, Malaysia (MY):
https://sg-urc.io.mi.com
https://github.com/junyongtio-lab/test-2/tree/main/tools/mi_stb
Response JSON, timestamps, hashes and original offline conversion are retained.
The source returns code-set IDs, without Ultra Box or Ulti Box retail labels.
These response data are attributed to Xiaomi/Kookong. Public availability does
not establish a reuse license; no MIT or AGPL license is assigned to them.

Six non-executable Panasonic 216-bit parameter profiles support an independently
written Java encoder. Three derive from the pinned APK database; three additional
profiles derive from the GitHub archive and retain its source notices. Framing,
packet fields, checksums and capability limits remain source attributed:
https://github.com/junyongtio-lab/test-2/tree/main/tools/panasonic_ac
This is not Mi Remote's complete AC engine. No vendor Lua, native library or
decompiled implementation is executed or copied into Palm Remote.

Combined raw coverage is 4,315 profiles and 165,369 command associations.
Six adjustable Panasonic profiles are counted separately.
See assets/ir/ATTRIBUTION.md for full source and format boundaries. The app uses
bundled data offline, makes no Xiaomi API requests and requires no phone JSON
import. Copied Xiaomi graphics and embedded vendor credentials are not included.
Earlier IR datasets, owner-supplied Astro JSON and the native IRremoteESP8266
engine remain removed since version 1.2.0. No manufacturer endorsement or
physical compatibility certification is implied.
